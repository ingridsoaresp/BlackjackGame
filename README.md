# ♠️ Blackjack Game

A Python implementation of the classic Blackjack (21) card game developed as an academic project.

## Overview

This application simulates a two-player Blackjack game using a standard 52-card deck. Cards are dealt randomly, hand values are calculated according to Blackjack rules, and the winner of each round is determined until the deck no longer contains enough cards to continue.

The project was created to practice Python programming fundamentals, problem-solving, and game logic.

---

## Features

- Two-player gameplay
- Random card dealing
- Standard 52-card deck
- Automatic hand value calculation
- Ace value adjustment (1 or 11)
- Bust detection
- Round winner determination
- Game statistics
- Score tracking until the deck is exhausted

## Running the Project

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python blackjack.py
```

4. Enter the player names when prompted.
5. The game continues until there are not enough cards remaining in the deck.

---

## Game Rules

- Players receive cards one at a time.
- Face cards are worth 10 points.
- Aces are worth 1 or 11, whichever produces the best valid hand.
- A player who exceeds 21 loses the round.
- If both players exceed 21, the round ends with no winner.
- The game ends when the deck no longer has enough cards for another round.
